# 开发归档

这里保存已经退出主运行路径的阶段性验收工具、旧测试、冻结数据集、原始证据和开发历史文档。

- `development_tools/`：A3–F4 阶段的 smoke、验收和实验脚本。
- `acceptance_tests/`：只验证上述阶段工具的旧测试。
- `evidence/`：冻结样例、原始运行目录和早期验收记录。
- `docs/`：精简前的开发过程文档。

这些文件不会进入 Python 安装包，也不会被默认 `pytest` 配置收集。项目运行和提交评审应以根目录文档、`src/testgen_agent/`、`tests/`、`examples/` 与 `evaluation/` 为准。
