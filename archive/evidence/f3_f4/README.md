# F3/F4 真实评测证据

正式结论见 [最终汇总](final/summary.md)、[逐案例表](final/cases.csv)、[验收与成本核对](final/acceptance.json) 和 [关系断言复核](final/relation_review.json)。可离线重建：

```powershell
python -m testgen_agent.experiment rebuild --run-dir evaluation/f3_f4/final
```

本目录顶层保留首次归档，包含最初的归因漏计及 Windows 框架错误；该次历史 `summary.md` 不能作为最终结论。`final/` 使用修正后的 pytest.raises 归因，并保留两次框架错误的首次记录及各一次本地复测。模型、Prompt、输入及生成测试未变，修正和复测没有新增 API 调用。

两方案均可运行 6/8、正确实现全通过 5/8。本次无追加反馈请求、无测试或覆盖提升。6 个已知变体中，基线可评测 4 个且全部检出，反馈可评测 5 个且全部检出；共同可评测的 4 个结果相同。均值基线因 Windows 文件替换错误仍不可评测，旋转任务未生成有效测试，因此不能把分母差异当作反馈提升，不能宣称检出全部 6 个缺陷。

行覆盖均值 100% 只对应 6 个覆盖可用任务；分支均值 100% 只对应 5 个有分支且覆盖可用任务，另有 2 个覆盖不可用和 1 个无分支。词首字符任务虽行覆盖 100%，仍有错误断言：`initials("straße test")` 应为 `"ST"`，模型写成 `"STEST"`。完整失败测试保留，未修改正确实现或降低断言。

物理 HTTP 请求 11 次，共享首轮仅计一次。其中可取得的用量为 50,208 tokens（prompt 35,062 / completion 15,146）；独立函数和旋转共 4 次 HTTP 的用量未返回到错误契约，所以完整 token 总量保持未知，50,208 只是已知小计。两方案分摊首轮的生成与控制器累计耗时分别为 106.791 / 107.604 秒，不包含 F4 独立复测时间。

订单及标签的确认调用边、入口与组合断言有效。独立函数案例在结构校验失败后没有可评测计划，不能据此宣称独立策略验证成功。所有结果只代表 8 个小任务的一次随机采样，是小型已知缺陷检出实验。

两个归档各有独立 SHA256 索引。原始路径保留用于诊断，重建不会跟随原路径读取；不含密钥、缓存或覆盖数据库。
